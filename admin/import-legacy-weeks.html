Import legacy weekly stats

This writes 3 historical weekly-stats snapshots — the summer season, weeks 1–3 (Sept 3, 10 & 17, 2026) — directly into your Firestore weekly collection, in the exact shape the Admin page's own "Save weekly stats" button produces. It does not touch players, nights, or anything the live scorer/board reads from — it only makes these 3 weeks show up in Admin → Stats & export → Download whole season (CSV).

Place this file inside your admin/ folder (next to admin/index.html) — it imports ../lib/backend.js, same as admin.js does, so it needs to sit at that same depth to find it. Run it once, then delete it — it has no password of its own. If your Admin page uses the Firebase-Auth login, sign into /admin/ in another tab first; this page reuses that same browser session.
